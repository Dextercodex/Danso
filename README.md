# دانسو — نسخه‌ی اندروید

ساخته‌شده توسط سبحان خلیلی — https://sobhan-khalili.ir

یک مرورگر کوچک (WebView) که لینک را باز می‌کند و همان موتور افزونه‌ی دانسو را داخل صفحه تزریق می‌کند.
دکمه‌ی «دانسو» پنل پایین را باز می‌کند: ۳بعدی (پیش‌نمایش + GLB/GLTF/OBJ/STL/PLY)، رسانه و اتصال.
فایل‌ها در `Downloads/Danso` ذخیره می‌شوند.

## ساخت APK بدون کامپیوتر (GitHub Actions)
1. یک ریپوی خصوصی در GitHub بسازید و همه‌ی فایل‌های این پوشه را آپلود کنید (از مرورگر گوشی هم می‌شود: Add file → Upload files).
2. تب **Actions** → «Build APK» → **Run workflow** (یا با هر push خودکار اجرا می‌شود).
3. بعد از ~۵ دقیقه، در صفحه‌ی همان اجرا، بخش **Artifacts** → `danso-apk` را دانلود کنید.
4. فایل زیپ را باز کنید و `app-debug.apk` را نصب کنید (اجازه‌ی «Install unknown apps»).

## ساخت با Android Studio
پوشه را باز کنید و Run بزنید، یا: `./gradlew assembleDebug`

## استفاده
- لینک را در نوار بالا بزنید، یا در مرورگر/تلگرام «Share → دانسو» را انتخاب کنید.
- صفحه را باز کنید، مدل را بچرخانید تا لود شود، بعد «دانسو» را بزنید.

## نکته‌ها و محدودیت‌ها
- ورود با Google داخل WebView معمولاً از طرف گوگل مسدود است؛ ورود با ایمیل/رمز یا لینک ایمیلی کار می‌کند.
- صحنه‌ی زنده فقط در صفحه‌ی اصلی (نه iframe) و برای three.js / model-viewer کار می‌کند.
- ویرایشگر SVG نسخه‌ی اندروید ندارد؛ SVGها فقط دانلود می‌شوند.
- حداقل اندروید ۱۰ (API 29).
